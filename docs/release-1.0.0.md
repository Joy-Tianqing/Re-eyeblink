# 1.0.0（build 2）

2026-10-23，首个代码仓库版本。保留当前已接受的眨眼识别、提醒、休息和测量行为；本轮只补齐后台 Dock 行为并更新版本。

## 窗口与菜单栏

- 主窗口或独立历史窗口可见时使用普通应用模式，显示 Dock 图标。
- 所有普通窗口关闭、最小化或应用被隐藏后，切换菜单栏应用模式，后台调度继续运行。
- 菜单栏“打开 Eyeblink”恢复普通模式、显示主窗口，并还原被最小化的窗口。
- 提醒浮层不参与 Dock 显示判断。仅切换到其他应用、但 Eyeblink 的普通窗口仍可见时，保留 Dock 图标。
- 保留关闭窗口不退出、退出时等待相机与数据收尾的行为。

## 验证

新增 8 项 `DockVisibilityTests`，覆盖关闭时通知先于可见性变化、历史窗口、多窗口、最小化恢复、隐藏、无新 key-window 事件的重新激活、提醒浮层排除及观察者注销。

全量 Release **213 项测试通过，0 失败**。发布包通过 arm64、严格签名、模型、许可证、动态依赖及版本一致性检查。界面“关于”显示 **1.0.0**。

实机读取系统进程的 activationPolicy：关闭窗口、隐藏后为 accessory；通过 Finder 重新打开后为 regular，并保持同一进程。最小化路径在首个候选包也验证为 accessory；最终包该路径未改。直接读取后台窗口的辅助功能树不等于执行“打开窗口”，因此恢复行为使用真实 Finder 打开操作核验。

运行期原始测试日志、验包和数据哈希记录保存在本机忽略目录 `evidence/native-tests/v1-*`。操作前后用户设置、既有 8 条测量历史、用户偏好及原版主程序逐字节不变。
