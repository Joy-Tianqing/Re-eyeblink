# 简体中文本地化方案

## 已有资产

从主程序嵌入的斯洛伐克语、捷克语和德语QM读取出每种237条，合并为237个唯一 `(context, source, comment)`、13个上下文；英文为源文本。恢复范围是编译翻译消息，不保证涵盖所有硬编码字符串和系统组件。

`evidence/static/localization-source-catalog.json` 保存英文和原有三种语言；`catalog/zh-CN.draft.json` 为完整中文初稿，所有条目仍是draft。`locales/eyeblink_zh_CN.ts` 由生成脚本输出，全部保留unfinished标记，供Qt Linguist后续校对。没有编译QM、修改已安装应用或证明中文UI可用。

术语统一为：Blink training「眨眼训练」，Eye exercises「眼部练习」，Computer breaks「离屏休息」，Blink rate「眨眼频率」，Blinks per minute「每分钟眨眼次数」，Presentation mode「演示模式」，Meibomian gland dysfunction「睑板腺功能障碍」。MGD保留为辅助缩写。统计数值明确标注「次/分钟」「毫秒」，分钟和秒不混用。

## 实现步骤

1. 新程序所有可见文案从启动前就接入翻译系统：主窗、设置、托盘、浮层、菜单、图表、通知、相机权限/错误、删除确认、更新器。不得先硬编码中文再建立另一份字典。
2. 本轮237键保持原上下文，便于与原资源对照。重写时新增或替换的键通过源码扫描增量维护，不以237作为永久总量。
3. Qt使用标准翻译工具输出QM并由QTranslator加载；同时覆盖Qt基础菜单/日期/对话框需要的中文翻译，参见 [Qt 官方本地化文档](https://doc.qt.io/qt-6/localization.html)。这条链路需要构建阶段验证，本轮没有安装工具链。
4. 简体中文为默认，英语回退；用户选择语言应持久化。切换后现有窗口、浮层、图表标签和菜单一起刷新，不重新启动检测任务，也不重置测量。
5. 继承原资源动画作为分析参照，重现时确认实际可用的资源来源；中文字形不能依赖原版只带的Roboto覆盖。文本容器自适应，支持换行与系统字号，不把英文宽度写死。
6. 历史Windows/授权/代理文案已忠实翻译供比对，但在首版UI范围外。2022公告不照搬为新项目现状；原作者信息与新项目身份分开。

## 文案处理原则

- `%1`、`%2`、`%n`等占位符保留名称和数量；富文本标签/属性、链接目标保留；技术数值和单位逐条核对。
- 原版的「我的工作比眼睛重要」等语气已忠实保存在初稿。新版建议按钮用「跳过本次」「5分钟后提醒」，这是明确的产品文案改写，不能冒充原文。
- 对干眼、睑板腺等说明按原意翻译，避免从「提醒/练习」扩写出未经验证的治疗承诺；过时帮助内容作为版本说明处理。
- 「Consider」与数值控件、下载进度中的「of」等拆分文本需要在成句UI中校对，不能只检查单条字典。疑问见 `catalog/translation-notes.md`。

## 中文准出

静态门槛：恢复源键一一对应、无空译文、占位符/HTML/URL一致、生成XML可解析，新增源码文案无漏扫。

运行门槛：主界面、设置、相机页、托盘、三种浮层、历史、错误、通知和删除确认逐页截图；正常/禁用/长文本/多屏/缩放状态无截断、遮挡或混合语言；切换与重启保留语言。需要实际编译运行后方能通过，当前未执行。
