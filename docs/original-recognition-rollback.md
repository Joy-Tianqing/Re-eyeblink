# 回归原版识别

后续：2026-10-23 按用户要求继续对齐剩余七组链路差异，包括采集/扫描与训练收尾；下文的“动画不在范围内”和旧验收数量属于2026-10-22阶段。最新范围和证据见 [识别链路对齐原版](recognition-chain-alignment.md)。

2026-10-22，用户要求将识别差异回归原版。

生产相机入口现在只调用 CameraFrameAnalysis：原 CNN 选脸、dlib 五点定位、Farneback 光流及原眨眼时间状态机。CameraPipeline / CameraFrameRun 不再接收检测模式或校准参数；以前保存的侧置开关不再读取，用户偏好文件无需迁移或清空。

已撤回：Vision 轮廓检测、默认单眼估计、三次眨眼校准、姿态缓存和移动门槛、空间目标锁定/重获清空校准、连续30秒质量失败、180秒测量85%覆盖率门槛，以及相应开关、适配按钮和提示。实验代码和专属测试移到 experiments/retired-side-camera，不参与编译或打包。

测量继续使用原180秒期限及固定分母；训练接受原算法输出的第一次眨眼。原有无脸/低FPS/模型及画面处理异常仍有效。相机唯一仲裁、故障与完成的顺序协调、用户定制提醒动画及历史持久化不在回退范围内。

旧记录的算法版本、单眼来源和覆盖率字段继续原样解码；已有单眼估计仍独立于双眼均值，避免把旧估计冒充原版测量。新记录不写侧置算法元数据。

验证使用完整180秒受控时间、原函数固定图像/事件夹具、真实生产帧入口及历史编码回归，不打开相机。自动测试与签名包核对不能代替用户自然坐姿下的实机准确率验收。

验收结果：全套169项通过；Release选定36项通过；新增5项回归覆盖生产训练/测量入口的原函数图像输出、首次眨眼直接触发、30秒后仍可检测、完整180秒低于85%覆盖率仍按原期限保存、旧历史与单眼估计兼容。目录校验、单arm64签名/模型/资源核对通过。

已替换并重启 build/Eyeblink.app，摄像头页实查已无侧置适配与校准入口。现有设置、8条历史及原版可执行文件哈希保持。真人自然眨眼准确率未在本轮验收。详见 evidence/native-tests/original-recognition-rollback.json 及同前缀日志。
