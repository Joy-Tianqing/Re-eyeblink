# 旁人入镜时的当前目标跟踪

> 2026-10-22 状态更新：侧置识别、目标锁定和质量门槛已按用户要求撤回；本文识别部分保留为历史设计，不代表当前生产行为。相机终止协调继续保留。见[回归说明](original-recognition-rollback.md)。

2026-10-22。用户的实际环境无法保证始终只有一人入镜，并要求先完成不需要本人配合的工作。本轮实现和测试完全离线；实机效果留待后续验证。

当前N114/N115将窗口稳定性和终止协调进一步收紧，结果来源为`side-contour-v4`/`spatial-primary-v2`。以下目标选择主体沿用v3；本轮改动详见[识别与稳定性设计](reliability-stability-design.md)。仍无当前包真人验收。

## 实际问题与范围

N111在完整180秒期限结束时只有74.5364%有效覆盖，因低于85%而没有保存。用户确认有人入镜。按状态日志近似积分，多脸约2.168秒、重新校准约32.353秒，不能把全部无效时间归因多人。

v2对任何多脸帧都停止检测。v3先建立一个明确的前景空间目标，之后在多脸帧继续寻找该目标，只对它请求眼部轮廓。目标混淆或丢失时暂停，避免直接换成背景里另一张脸。该能力是空间连续跟踪，不是身份识别；不保存人脸图像、视频或身份特征。

## 实现约束

- 保留唯一相机仲裁、capture队列、有序交付、generation与租约、预读和原180秒期限。没有增加相机会话或测量计时器。
- `FaceTargetTracker`只接收Vision归一化人脸矩形和单调时间。输入数组下标仅在当前帧有效，不能当作人的持久ID。
- 初始选择需要唯一可用脸，或面积至少为次大脸2.25倍的明确前景脸，连续确认0.3秒。v4保留窗口首框为参照，累计位移>0.2或IoU<0.5即重启确认，避免逐帧小步漂移被当作稳定。大小相近的多人组保持不明确；矩形至少宽高0.04、有限且位于图像内。
- 已锁定时不再按最大脸排序改目标。候选相对旧框的中心位移须≤0.35个面积平方根单位、面积比0.6–1.65、IoU≥0.3。按位移、尺度和重叠排序，前两候选评分差<0.25则暂停。这些是初始可测参数，不是已标定的身份或跟踪准确率。
- 目标消失时保留原空间锚点，不跳到其他位置唯一剩下的旁人。“适配我的坐姿”、设备或分辨率改变会重新选择目标。
- 丢帧>0.2秒、乱序时钟、目标丢失或候选重叠会中断连续性。重新确认后递增目标版本，清除旧眼部基线及半次候选，重新校准。目标一直明确时，旁人出现/离开或检测数组重排都不更换版本。
- 租约重开会重新确认同一空间锚点，取消在途候选；空间目标版本保持时可复用数字校准。Vision预读只预热请求，不能改目标。
- 空间跟踪无法可靠区分同位置、外观/尺寸相近且无可观测中断的人员替换。交叉或遮挡有可观测歧义时暂停；不能把“已锁定”宣传为已认证某个人。

## 与计数和界面衔接

原始画面人脸总数保存在目标反馈中；`CameraObservation.faceCount`在增强分支表示选中的目标数，最多1，原版分支仍表示原始选脸结果。计数有效性同时要求目标已跟踪、眼部校准完成和现有质量约束通过。

摄像头页显示目标锁定状态及多人反馈，测量页说明旁人可入镜、持续目标丢失/混淆会停止。关闭侧置增强后仍使用原版规则，中文和英文说明分别对应实际策略。

当前测量记录标记`side-contour-v4`、`targeting=spatial-primary-v2`及已有单/双眼来源；N112/N113包曾使用v3/v1标记。旧v1/v2/v3及无元数据记录兼容读取，不重算旧记录。单眼或混合结果继续标“单眼估计”，不进入双眼均值。85%有效覆盖率和连续质量不足30秒终止保持。

## 离线验收

- 几何序列：稳定锁定、大小优势/相似多人、旁人更大、数组重排、目标丢失、重叠、平滑移动、租约确认、显式重新选择、乱序/非法几何。
- 计数串联：旁人存在时十次标注合成闭合仍各计一次；目标丢失/重叠不拼接半次眨眼；重获需要校准；租约不继承候选；旧目标版本的乱序帧不能绕过时钟校验。
- 完整180秒合成多人流保留有效覆盖率及版本来源。它验证算法契约，不代表真实相机180秒成功。
- 实际Vision：从现有公开人脸夹具在内存生成固定前景/背景双脸图，验证先锁定前景、旁人出现仍只提取目标眼轮廓、目标移除不改跟旁人。另一用例验证预读不能覆盖已有目标。无用户相机或图像文件输出。

后续实机验收：自然坐姿校准；背景旁人路过时的目标连续性与十次人工计数；交叉混淆/离席时暂停且无拼接；完整180秒、版本化历史追加、通知及重启保留。当前不要求用户清空背景，也不把这些未执行项标为通过。
