# 原生 macOS 界面设计

本实现采用 SwiftUI / AppKit，最低 macOS 14，面向 Apple Silicon。设计参考项目中归档的 [apple-design](references/apple-design.SKILL.md) 与 [Apple macOS Human Interface Guidelines](references/apple-macos-hig.md)。原作的功能行为是复刻对象，窗口皮肤和排版不照搬。

## 设计决策

- 使用标准 `NavigationSplitView` 和侧栏：眨眼训练、休息与眼操、眨眼统计、摄像头、设置、关于。功能按任务组织，原生窗口工具栏始终提供全局暂停/恢复。
- 设置使用 grouped Form、Toggle、Picker、Stepper、DatePicker、标准按钮与系统确认对话框。采用系统 SF / 中文系统字体、SF Symbols 和语义颜色；teal 仅用于强调主操作与图表。
- 首屏围绕当前任务给出简短说明和操作，不放占位统计或虚构的使用成果。统计在零记录时显示真实空态；日期筛选、图表选中值、可读历史条目和清空确认均使用真实模型数据。
- 相机请求由用户触发；预览页说明本机处理及预览不入统计。未授权、暂停或无设备时关闭不可执行动作，并保留真实状态文本与系统隐私入口。
- 完成通知显示系统授权状态，并提供明确授权/通知设置入口；已授权时可发送不会写入历史的测试消息，并从系统回读其送达状态；真实测量通知单独显示最近一次的提交/送达结果，测试消息不会替代这一状态。系统专注模式及样式保持用户选择，不把提交成功写成横幅可见。
- 控制顺序和标签支持键盘与 VoiceOver。全局暂停快捷键为 `⌘⇧P`。图表同时提供文本记录；数值步进控件包含可访问名称和值。使用系统控件的焦点和按下反馈，不叠加持续动画。`accessibilityReduceMotion` 开启时移除自定义视图事务动画。
- 语言选择立即绑定应用设置，页面中的应用文案统一通过 `model.text(中文, English)` 提供。保留专有名词与原作外链身份，原作隐私政策不冒充新版政策。
- 原 Mac 版无有效行为证据的屏幕调整、旧许可/付费、旧更新与研究上传不显示为可运行开关。功能账本继续保留候选，设置只呈现使用者需要的隐私说明。

## 页面与功能覆盖

| 页面 | 当前接线 |
| --- | --- |
| 眨眼训练 | 总开关、定时/低频提醒、间隔、MGD、声音、提醒预览 |
| 休息与眼操 | 休息间隔、连续空闲完成条件、自然休息抵扣、眼操开关/固定周期、休息及眼操预览 |
| 眨眼统计 | 固定30分钟/3分钟测量说明、完成通知及系统授权状态、立即测量、进度、日期筛选、均值与时长、曲线选中、历史文本、清空确认 |
| 摄像头 | 授权、隐私入口、设备选择、摄像头开关及独立暂停、预览与状态 |
| 设置 | 中英文、登录启动、摄像头/进程/窗口关键词暂停及前台规则、隐私与平台边界 |
| 关于 | 版本、技术与独立重现身份、原作 FAQ/MGD/条款参考链接 |

提醒浮层、菜单栏、相机处理和系统集成由 AppModel 及相应原生实现负责。本页面清单只说明 UI 接线，不能代替功能行为验收。

## 验收状态

当前已实际构建、签名和运行，六页界面、中英文切换、真实相机与测量图表、部分日期筛选、清空取消及浮层操作已有证据，详见`native-acceptance.md`。浅/深色、最小窗口、完整键盘与VoiceOver、减少动态效果、权限拒绝/撤销和所有菜单栏动作仍需专项验收。不得把可见控件或源代码检查记为行为通过。
